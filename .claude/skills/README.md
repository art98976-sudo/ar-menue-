# Project skills

Grilling skills from [mattpocock/skills](https://github.com/mattpocock/skills) (commit `4ae2317`, MIT License, © 2026 Matt Pocock).

| Skill | Invoke | What it does |
|---|---|---|
| `grilling` | auto, or say "grill me" | Relentless round-based interview to stress-test a plan, decision or idea |
| `grill-me` | `/grill-me` | Shortcut that loads `grilling` |
| `grill-with-docs` | `/grill-with-docs` | Grilling plus `domain-modeling`: writes `GLOSSARY.md` and ADRs in `docs/adr/` as decisions settle |
| `domain-modeling` | auto | Sharpens domain terms, maintains the glossary and ADRs |
